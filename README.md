# Assistente Gravity para macOS

Aplicativo nativo para localizar arquivos em pastas escolhidas no macOS, com interface Liquid Glass.

## Código-fonte

Baixe o pacote público sanitizado em [`assistente-gravity-macos-public.zip`](./assistente-gravity-macos-public.zip). O histórico de desenvolvimento e o repositório de trabalho permanecem privados.

## Requisitos

- macOS 26 Tahoe ou posterior
- Mac com Apple silicon

Este repositório contém código-fonte, não um aplicativo assinado e notarizado. Leia `docs/PRIMEIRO-USO.md` antes da instalação.
